# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Dual Licensing & Enterprise Security
Please note that `AIGrid-Planner` follows an Open-Core model. 
If you find a vulnerability in the Open Source `aigrid_planner_core` module, please report it.
If you are an Enterprise customer and find a vulnerability in `aigrid_planner_pro`, please contact your account manager directly.

## Reporting a Vulnerability
To report a security issue, please email `byemir@live.com`. We will respond within 48 hours.
